# 数据质量与刷新边界

## 来源与解析

十七个固定来源见 src/lib/source-defs.ts 和 SOURCES.md。LINUX DO 经 Jina Markdown，Epic JSON，Hacker News 用 Algolia JSON，两个 GitHub 清单分别是 Markdown 表格和 programs JSON，其余 RSS/Atom。普通 feed 只允许本来源域名内的 http(s) 条目链接。两个写死的 GitHub 清单保留表内 https 链接，仍不接受凭据和超长 URL。标题 300 字，摘要 160 字，缺字段不猜。只存索引，不宣称已核实可领。AI 节点和 AI 清单在入库前丢掉不像优惠的标题；提问、求购、抽奖即使出现「免费」或「额度」也不算 AI 优惠。

每源 25 秒总超时，响应流最多 150 万字符。RSS/Markdown 每源最多 2000 条；这不是看板累计总量。共享日期校验：早于 2000 年或晚于 now+7 天记 null，留存改用首次见到时间。

429/503 最多重试两次，500/1000ms 指数退避且等待不短于 Retry-After；超过 5 秒的等待推迟到后续轮次，调用方信号可中断。连续三轮请求失败熔断 10 分钟；上游要求更长等待时尊重更长值，但封顶 6 小时，避免一个离谱的 Retry-After 把来源停好几天。状态可区分缺 Jina key、限流、结构异常、熔断。没有 key 不等于一定被限流，不自动绕过站点挑战。

Epic 必须有非空商品列表及关键字段；逐条校验标题、价格与促销结构，任何结构异常让整源失败，旧记录不因 reconciliation 被删除。健康目录无当前免费促销才允许返回空并下架；活动到期仍按真实 expiresAt 隐藏。非空但字段改名、类型变化、混入异常条目均有回归测试。

## 分类与展示

classifySignals 返回类别、内容类型、置信度及分数：明确优惠加分（限免、优惠码/券、折扣、促销、特价、返现、羊毛、红包、注册送额度等），抽奖/求购、二手买卖帖（「200 出 xx」「+50 收 xx」「【出】」「拼车」）、编辑性讨论和提问句扣分。Pro 不独立决定会员；问号、更新/公告不会单独否决明确优惠。它仍是启发式分类，不是真实性/资格证明。

默认读取时重算基础分类，不改历史 category；PERKRADAR_STORED_CATEGORIES=1 可回退。AI 分类不进数据库，每次读取按标题和摘要重算。首页默认只看 AI，偏好键是 perkradar-ai-only-v1，缺省为开；「查看全部线索」仍只控制「其他」。搜索不隐藏其他。AI 优惠即使基础分类是「其他」也会留下。分类只是展示，不改变已经通过来源规则的收录。重置节奏只接受原文里的每日、每周、每月或滚动额度，不生成下一次重置时间。截止日期只接受和 until、expires、截止、到期写在一起的日历日期。

API 支持 offset/limit（默认500，最大2000），返回 total/hasMore；网页逐页读取，100条一组展开，显示范围。客户端安全总上限独立为10万条，超过会提示而非伪装成完整清单。visible 页面每30秒重新读，重新聚焦立即读；请求15秒超时。过期状态会本地重算，断网保留旧数据并告警。

## 留存、调度与历史

无真实截止时间时按 publishedAt 或 firstSeenAt 留存7天：正好7天仍保留，更早才淘汰；有 expiresAt 时到点立即淘汰。7天仍是统一存储留存上限，不代表活动真实有效期；非Epic没有猜测截止日期。

单Node实例调度每2小时；SQLite持久化 scheduler 租约、20秒心跳、90秒超时，租约被别人持有时本进程照常启动并提供页面，只是不抓取，每 20 秒再试；上个进程被强杀后最多等 90 秒自动接管，正常停止会立即释放。刷新另有180秒租约、提交前验证；过期持有者不能提交。首次/超期启动约4秒后只补一次当前抓取，未超期等待剩余间隔，不重放错过的所有轮次，也无法追回上游滚出的帖子。调度每 20 秒拿墙上时钟和到期时间比较，所以机器休眠醒来后会马上补一轮，而不是等旧定时器走完；全部来源失败的一轮 10 分钟后重试，连续失败时间隔翻倍、封顶 2 小时。显式 DEALS_SKIP_BOOT=1 保留跳过启动检查行为。

每轮写入事务内保存 source_runs、清理过期优惠、清理30天前历史（保留最近完成轮次）；单源抓取失败不改写已有字段，但过期优惠仍按共同规则淘汰。手动冷却60秒、每10分钟8次，并要求配置的身份认证。全失败/关键结构异常让 live report 返回非零；部分失败仍输出告警与报告。

/api/health 的200/ok只代表数据库可读，不代表数据新鲜或抓取成功；同时看 freshness、sourceHealth、failures、diagnostic 和 anomalies。快照必须显式配置目录。
